# Philosophers

## Description
A simulation of the classic dining philosophers problem, implemented in C with POSIX threads and mutexes.



## Instruction

```
./philo <num_philosophers> <time_to_die> <time_to_eat> <time_to_sleep> [times_must_eat]
```
